# Paper (LaTeX)

`main.tex` + `references.bib` + `figures/`. Compiles with pdfLaTeX on Overleaf (New Project → Upload
Project → select `paper_overleaf.zip`, or upload this folder's files).

Figures are generated from the data by `python analysis/make_paper_figures.py` (run `python
analysis/analyze_results.py` first). Re-run both if the trial log changes, then re-upload `figures/`.
